R413E16 documentation

Verified Modbus RTU reference used by the tested R413E16 template. The board is a 5 V TTL output core; it needs compatible external relays or output hardware.

Connection defaults

RS-485 Modbus RTU: 9600 baud, 8 data bits, no parity, 1 stop bit. Default slave ID: 1. Valid IDs: 1–247.

Channel commands

Use function 06 (write one holding register), register 1–16:

  • ON: 256 / 0x0100
  • OFF: 512 / 0x0200
  • Toggle: 768 / 0x0300
  • Interlock: 1024 / 0x0400
  • Momentary one-second pulse: 1280 / 0x0500
  • Timed action: 1536 + 0–255 seconds

Read holding registers 1–16 with function 03 for channel state: 1 = ON, 0 = OFF.

Settings and safety

Baud register 254: 0=1200, 1=2400, 2=4800, 3=9600, 4=19200. Slave ID register 255 accepts 1–247. Value 5 at register 254 is a factory reset—use only the confirmed Reset action in the integration, then power-cycle the board.

Interlock turns other channels off. A Combined Switch sends the normal ON/OFF command to every selected channel; you can create more than one combined group.
